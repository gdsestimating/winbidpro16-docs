Set specific vertical/horizontal elements to an alternate parts assembly defined in the Framing System menu.

<div class="app-img"><img src="/screenshots/tool-tabs/editor-alt-3.png"/></div>


The Alternates Tool Tab will show a list of alternates assigned to the frames in your current elevation. You can use this list to quickly review, or delete assigned alternates.

If alternates haven't been assigned, the list will show `No Elements with Alternate Assemblies`.

## Set Alternate

To set an altenate, click the `Edit` button. 

Your tab will switch to a new view where you can assign alternate assemblies to selected frame segments.

<div class="app-img"><img src="/screenshots/tool-tabs/editor-alt-2.png"/></div>

:::note
    You'll only be able select one type of assembly at a time -- for example, right jambs.
    
    `Save` or `Cancel` to set alternates for other types.
:::

:::info
    To set any alternates, the assigned framing system needs to have more than one assembly availble for the chosen frame type.

    {/* See [Configuring a Framing System](/docs/v16/configuration/framing-system) for more details */}
:::

### Options

* `Alternate` - Choose an alternate assembly from those available in your framing system.

* `Add New Alternate Assembly` - This will open a configuration window where you can configure a new assembly for the frame type you selected.

### Confirm / Return

Click `Save` to confirm your settings and apply them to the elevation.

Click `Cancel` to return to the list of alternates applied to the elevation.
