The Annotations Tool Tab is used to add notes and leaders to your elevations. You can use this list to quickly review, edit, or delete annotations applied to this elevation.

If annotations haven't been added to this elevation, the list will show `No Notes`.

## Adding Annotations

Click the `Add Text` or `Add Leader` button to create a new annotation.

Your tab will switch to a new view where you can add each of these to the current elevation.

<div class="app-img"><img src="/screenshots/tool-tabs/annotation-leader.gif"/></div>


### Types

* `Add Text` - Text placed on the elevation.
    * You'll be prompted to click on the elevation to set the text position.

* `Add Leader` - Text with a leader placed on the elevation.
    * You'll click once to set the target of the note, and then click a second time to set the position of the text. 

You can undo your text or target positions by pressing the `Esc` key.

You can also reposition text by left-clicking a new spot.



### Options

* `Note` - The text you want to add to the elevation.

* `Scale` - Option to increase or decrease the front size.
* `Color` - Option to color the text.

### Confirm / Return

Click `Save` to confirm your settings and return to the annotation list.

Click `Back` to cancel and return to the list of annotations applied to the elevation.
