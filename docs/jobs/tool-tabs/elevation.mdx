Set the basic panel layout, sizing and framing system details.

<div class="app-img"><img src="/screenshots/tool-tabs/editor-layout-1.png"/></div><br/>

The Elevation Tool Tab is used to set the basic options for an elevation, including its height, width and quantity.

:::info
        You'll need `Original Width`, `Original Height`, and `Panels` filled out before a preview of the elevation can be drawn. 
:::

## Options

* `Quantity` - Number of times this system appears in a job.

* `Panels` - Number of glass panels between the left and right jamb.
* `Edit Framing System` - Allows you to modify the applied framing system on the current elevation only.
        * Any changes made here will create a copy of the framing system which can then be synced to the catalog.
                {/* * See [Understanding Configurations](/docs/v16/getting-started/understanding-configuration) for more details. */}
* `Original Width` - The rough opening width.
* `Original Height` - The rough opening height.
* `Caulk Joints` - Modify the Framing System’s default caulk joint sizes at each edge **for this elevation only.**
        * `L` - Caulk joint at the left jamb.
        * `R` - Caulk joint at the right jamb.
        * `T` - Caulk joint at the top / head.
        * `B` - Caulk join at the bottom / sill. 
* ☑ `Force equal width panels` - Toggle forced equal spacing of verticals.
