Visualize joints as they apply to your active elevation.

<div class="app-img"><img src="/screenshots/tool-tabs/editor-joint-1.png"/></div>

<br/>

:::info
    The Joints Tool Tab is used to visualize where each joint type is applied in your current elevation.
    
    To set or modify joints, see the Joints tab of the Framing System configuration menu.

    {/*See [Configuration - Joints](/docs/v16/configuration/joints) for more details.*/}
:::

## Visualization Options
* `Highlight Options & Statistics` - Allows you to toggle showing each type of joint individually and lists how many of each exists in the current elevation

    * `Show Parts` - Toggles showing part numbers used in a joint, near each joint
* `Joint Configuration Colors` - Allows you to set the color of each joint type in the current elevation
* `Edit/Add Joint Configuration` - Opens a configuration window for the joints in the current Framing System
    {/* See [Configuration - Joints](/docs/v16/configuration/joints) for more details*/}
