Assign and modify a labor configuration to generate pricing estimates. 

:::info
    The Labor tab is being replaced with a new dedicated Labor configuration window. This can be opened from the `Job` menu in the tool bar by selecting `Labor Rules and Settings` or by pressing `Ctrl` + `L`

    For now, the Labor tab will open this window next to your elevation but will eventually be removed from the Tool Tabs.

    See the [Labor Rules](/docs/v16/jobs/labor-rules) tab for more details on setting labor.
:::
