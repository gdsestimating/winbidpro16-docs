Apply stop or operable window adapter options to selected daylight openings.

<div class="app-img"><img src="/screenshots/tool-tabs/editor-stopadapter-1.png"/></div>

The Stops/Adapters Tool Tab will show a list of Glass Stops and Adapter Options in the current framing system.

If stops or adapters haven't been added to this framing system, the list will show `Start by adding an option to your framing system`. These cannot be added without any configured in your assigned framing system.

:::info
    Stops and adapters can be assigned in a few different ways for different applications. If a panel has had one or more options assigned in multiple locations, the priority is:

    1. Stop/Adapter Tool Tab assignments
    2. Door Frame transom settings
    3. Auto Applied per frame configuration
:::

## Adding Options

* `Edit/Add Options` - Add or modify stops and adapters available with this framing system. See [Configuring Stops and Adapter Options] for more details.

## Assigning Stops / Adapters

### Process

To assign stops/adapters to the current elevation, make sure a stop/adapter options is loaded and available from the list. Select the glass product you want to use, click `Add`, and then click the panels you want to apply them to.

:::info
    Operable Window Adapters can only be applied to panels with an operable window assigned.
:::

<div class="app-img"><img src="/screenshots/tool-tabs/editor-stopadapter.gif"/></div>

### Options

* `Add` - Assign the currently selected stop/adapter to the panels you click.

* `Delete` - Remove stop/adapter from the panels you click.

There are also some options here to help speed up glass assignment:

* `By Lite` - Default option. `Add` or `Delete` stops/adapters on individual panels.

* `By Row` - `Add` or `Delete` stops/adapters for a full row of panels.
* `By Elevation` - `Add` or `Delete` stops/adapters to all panels in the elevation.

Once a stop/adapter is applied to a panel, the elevation view will update the line work to represent it. By default, these are pink in the Layer Settings.
