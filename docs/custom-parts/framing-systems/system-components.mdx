## Component Types

### Assemblies
* `Head Assemblies` - Horizontal frame assemblies at the top edge of the opening.
    
    * `Head Receptor` - Head components used for anchoring, or certain edge cases.

* `Horizontal Assemblies` - Any intermediate horizontal frame assemblies.

* `Sill Assemblies` - Horizontal frame assemblies at the bottom edge of the opening.

    * `Sill Receptor` - Sill components used for flashing, anchoring, or certain edge cases.

:::tip
    For verticals slotting into Can / Stick systems, those systems will typically use `Head Receptor` and `Sill Receptor` for their heads and sills.

    See the [Tips - Framing System Types](./tips#can--stick-systems) for more details.
:::

* `Left Jamb Assemblies` / `Right Jamb Assemblies` - Vertical frame assemblies at the left and right edge of the opening.

* `Vertical Assemblies` - Intermediate vertical frame assemblies.

:::tip
    Butt glazed systems can be achieved by setting the profile of the `Vertical Assembly` to 0".

    See the [Tips - Framing System Types](./tips#butt-glazed-systems) for more details.
:::


* `Stops` / `Operable Window Adapters` - Special assemblies at panel perimeters to handle operable windows and other edge cases. These are the same components found in the Opening Options tab.

    * See [Opening Options](./opening.md) for more details.

### Other

Other components cover individual parts in common use cases, including:

* `Glazing Gasket` - Measures the perimeter of the DLO + Glass Bite for each glass panel in an elevation to generate the length of these parts. 

* `Perimeter` - Measures the perimeter of the framing system to generate the length of the these parts.

* `Per Elevation` - Multiplies these parts by the number of times this framing system is applied to elevations in your job.

* `Per Lite` - Multiplies these parts by the number of panels in the elevation.
