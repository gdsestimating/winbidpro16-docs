:::info
    Cassette Systems need extra set up to account for extrusions in the cassettes and alternate assemblies at expansion horizontals.
    
    To set this up correctly, we'll make some alt assemblies in `Components` and set some rules in the `Joints` and `Opening Options`.
:::

:::warning
    As you're building out your assemblies, do not include the framing at the cassettes. We'll be using `Opening Options` and `Stops` assemblies for those so we can set them per glass panel.
:::

---

## Additional Configuration Steps

Follow the typical configuration steps for a framing system up to this point, then add the following assemblies and options.

* We'll be using the `Joints` tab for these systems, so pay special attention to where you assign hardware in your `Components` tab. 
    * See the [Joints Tab](../framing-systems/joints.mdx) page for more details.

### Horizontal Assembly
Add an alternate `Horizontal Assembly` in the `Components` tab:

> **Expansion Horizontal** - Include parts for the expansion horizontal to be applied at vertical splices.

### Stops Assemblies
Create three `Stops` assemblies in the `Components` tab or the `Opening Options` tab:

> **Standard Frame** - These are your default cassette framing assemblies along one edge of the cassette.  We'll be using this for all standard edge conditions.

> **Expansion Sill** - Include the parts needed at the bottom frame of a cassette when an expansion horizontal is below.

> **Expansion Head** - Include the parts needed at the top frame of a cassette when an expansion horizontal is above.

### Add New Opening Options
Use the `+Add New Options` button in the `Opening Options` tab to create the following three options. See [Opening Options Tab](../framing-systems/opening.md) for more details.

>        **Standard Cassette**
>            * `Type`: `Glass Stops`
>            * `Assign`: `All Sides`, `Standard Frame`
>            * `Auto Applications`:
>                * Toggle on - `Apply as default to all Lites ( not operable windows )`
>                * Toggle off - `Apply as default to all Operable Window Openings`
>            * Set `Horizontal Continuous` / `Vertical Continuous` based on vendor requirements.
>                * This sets whether the horizontal or vertical framing takes priority for cuts at corners.

>        **Expansion Horizontal Below**
>            * `Type`: `Glass Stops`
>            * `Assign`: `Each Side`
>                * `Left`: `Standard Frame`
>                * `Top`: `Standard Frame`
>                * `Right`: `Standard Frame`
>                * `Bottom`: `Expansion Sill`
>            * `Auto Applications` - Toggle both of these off.
>            * Set `Horizontal Continuous` / `Vertical Continuous` based on vendor requirements.

>       **Expansion Horizontal Above** 
>           * `Type`: `Glass Stops`
>           * `Assign`: `Each Side`
>               * `Left`: `Standard Frame`
>               * `Top`: `Expansion Head`
>               * `Right`: `Standard Frame`
>               * `Bottom`: `Standard Frame`
>           * `Auto Applications` - Toggle both of these off.
>           * Set `Horizontal Continuous` / `Vertical Continuous` based on vendor requirements.

### Configure Joints

In the `Joints` tab, configure all joint conditions based on vendor requirements at different conditions. See [Joints Tab](../framing-systems/joints.mdx) for more details.

You'll most likely need a joint configuration for each of the following:

> * When `Head Receptors` meets `All Jambs`
> * When `Sill Receptors` meets `All Jambs`
> * When `All Heads` meets `All Verticals`
> * When `All Sills` meets `All Verticals`
> * When Horizontal (default horizontal) meets `All Verticals`
> * When Expansion Horizontal (see above) meets `All Verticals`

## Drawing Elevations

With these options configured, draw your elevations. 

By default, your elevation have all panels set to the Standard Frame stops and the default horizontal option at all horizontal. From here, we'll apply the expansion horizontal and the alternate stops/adapters using tool tabs. 

* For elevations where a vertical splice is needed: 
    * Using the `Alternate` tool tab, apply the expansion horizontal assembly at the horizontal aligned with the vertical splice.
    * Using the `Stops/Adapters` tool tab:
        * Apply expansion sill to the panels above the expansion horizontal.
        * Apply expansion head to the panels below the expansion horizontal.

As long as they're configured correctly, the joints should apply themselves. You can review them using the `Joints` tool tab.
