---

:::warning
    Changes made to framing systems will effect your shop drawings and final reports. It's important to know what configurations are possible, and that they're set up correctly before using them on an active job.
:::

## Framing System Settings

<div class="app-img"><img src="/screenshots/configuration/config-frame-settings.png"/></div>

* `Series` - The make or product line this system is part of.

* `Description` - A brief description of the specific system being configured to help distinguish it in a list view.

    * Example: [Series] : Storefront : Screw Spline : Thermal : Center Set : Outside Glaze

* `Category` - Type of system. Options include:
    * `Storefront`
    * `Window Wall`
    * `Curtain Wall`
    * `Frameless Partition`
    * `Window`
    * `Other`

* `SSG Type` - Type of structural silicone glazed system, if relevant. Options include:
    * `None`- Typical for non-curtain wall systems.
    * `Vertical SSG`
    * `Horizontal SSG`
    * `4-Sided SSG`

* `Default Profile` - System profile measured in inches from the bottom edge to the top edge of the frame assembly in section.

* `Depth` - System depth measured in inches from the outside face to the inside face in section.

* `Glass Thickness` - Thickness of the glass product used for this system.

* `Glazing Method`
    * `Outside`- For use in exterior applications.
    * `Inside`- For use in interior applications.
    * `Other` - Edge cases and specialties.

* `Glass Position` - Position of glass lites within the framing system. Options include:
    * `Center`
    * `Offset`
    * `Front`
    * `Back`
    * `Other`

* `Joinery` - Method of assembly. Options include:
    * `Screw Spline`
    * `Shear Block`
    * `Can/Stick`
    * `Mixed`
    * `Other`

* `Default Caulk Joint` - Default depth / thickness of caulk joints along the perimeter of the system. Can be changed per elevation in the [Elevation Tool Tab](../../drawing-elevations/elevation).
    * `L` - Caulk joint at the left jamb.
    * `R` - Caulk joint at the right jamb.
    * `T` - Caulk joint at the top / head.
    * `B` - Caulk join at the bottom / sill. 

* `Default Glass Bite`
    * `L/R` - Glass bites size at the vertical edges (Left / Right) of the DLO.
    * `T/B` - Glass bites size at the horizontal edges (Top / Bottom) of the DLO.

* `Assembly Settings` - Toggle including face covers and pressure plates in the system configuration.
    * ☑`Has Face Covers` 
    * ☑`Has Pressure Plates`

---

The following toggles can differ between systems, and will effect cut lengths based on how the system comes together.

* ☑`Wall Jambs Interrupt Head`
* ☑`Wall Jambs Interrupt Sill`
* ☑`Has Head Receptor`
* ☑`Has Sill Receptor`
* ☑`Wall Jambs Interrupt Head Receptor`
* ☑`Wall Jambs Interrupt Sill Receptor`
* ☑`Door Jambs Interrupt Sill Receptor`

---

* `Web Link` - A link to the product page on the vendor's website or a download link for vendor catalog or installation instructions.

* `Notes` - A place to freely add notes about the system.

---

* `Report Config. Issue...` - Use this button to report an issue with the system to GDS.

* `Save to Catalog...` - This button will add the edits you make here to the catalog if the edits are made in an active elevation

    * See [Local & Global Edits](../../features-and-tips/config-levels) for more details.

---

* `Cancel` / `Save` - Discard or save the changes made on the Settings page.
