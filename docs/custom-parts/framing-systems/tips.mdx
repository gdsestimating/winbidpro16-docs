## Tips

These configurations are officially supported in WinBidPro v16 but have some added set up when first configuring them. Follow these settings to get the most accurate counts.

### Can / Stick Systems

:::info
    For these, we want to have vertical assemblies enough extra length to slot into the head and sill. This is especially important for raked elevations.
:::

* `Head Assembly` / `Sill Assembly`

    * Set the `Reveal` to 0"

* `Head Receptor` / `Sill Receptor`
    
    * Set the `Vertical Trim` to the dimension from the base of the receptor profile to the end of the vertical. 
    
    * In this example, the vertical is drawn in yellow. The 13/32" dimension is what we want for the `Vertical Trim`.

<div class="app-img"><img src="/screenshots/configuration/vertical-trim.png"/></div>

### SSG Systems

:::info
    These are some additional settings made to handle SSG conditions.
:::

* In the `Settings` tab, set your `SSG Type`. Options include:
    
    * `None` 
    * `Vertical SSG`
    * `Horizontal SSG`
    * `4-Sided SSG` - (vertical & horizontal)

* In the `Components` tab, toggle `Is SSG` in your vertical / horizontal assemblies.

    * Set the `Silicone Width` for each assembly.

* See also - [Tips - Face Covers / Pressure Plates](./covers-plates).



## Tricks

These configurations are not supported with dedicated settings, but you can approximate them with these settings.

### Butt Glazed Systems

:::info
    The key for these systems is to set a continuous head and sill receptor, then create verticals / jambs with small profiles and no glass bites.
:::

<div class="app-img"><img src="/screenshots/configuration/butt-glaze.png"/></div>



* In the `Settings` tab, toggle on `Has Head Receptor` and `Has Sill Receptor`

* In the `Components` tab:

    * `Head Receptor` / `Sill Receptor`

        * Add your head and sill extrusions here to make them continuous.
        * Match the `Vertical Trim` to the `Profile` dimension.

    * `Head Assembly` / `Sill Assembly`

        * Leave these assemblies empty.

    * `Vertical Assembly` / `Left Jamb Assembly` / `Right Jamb Assembly`

        * Create a new assembly.
        * Set `Profile` to the recommended size of the gap between glass lites.
        * Set `Glass Bite` to 0"
        * `Parts`
            * For silicone spacers, add or create a new part via the `+Browse List` button
                * See [Configuring Parts](../config-parts.mdx) for more details.
            * For an air gap, you can leave the parts list empty.

### Brake Metal / Structural Gaps

:::info
    By creating extra panels with 0" widths, we can triple up verticals and set the middle vertical to an alternate assembly to represent a structural gap.
:::

:::warning
    <img align="right" src="/screenshots/configuration/break-metal-warning.png"/>

    This trick should only be used for visual reference, not for cost estimation. Verticals cannot interrupt head / sill receptors so the counts for receptors and brake metal will not be entirely accurate. See image on the right for reference.
    
    For accurate frame estimates, a structural gap should be excluded and the framed openings on either side should be separate elevations.

    <br clear="right"/>
:::

<div class="app-img"><img src="/screenshots/configuration/brake-metal.png"/></div>



* In the `Components` tab:

    * Create a new `Vertical Assembly`
        * Do not delete the existing assembly or change the default.
        * Name the assembly something easy to recognize like `Brake Metal`
        * Set the `Profile` of your new assembly to the width of the gap.
        * Toggle on `Interrupt Head` and `Interrupt Sill`.

* In your Elevations:

    * Add two panels in the `Elevation` tool tab.
    * For the panels on either side of the gap, add set the panels to a fixed width of 0" in the `Adjust Panels` tab.
    * Set the middle vertical to the new assembly using the `Alternate` tab.
