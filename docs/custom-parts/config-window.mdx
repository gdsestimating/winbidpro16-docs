## Template Options

* `Description` - Required. Description / name of the door leaf.

* `Show Label` - Elevation label for windows of this type.

* `Type` - Type of operable window / vent. Options include:

    * `Hinged`
    * `Hung`
    * `Sliding`

* `Default Profile` - Default stile / rail profile height.

* `Height Deduct` / `Width Deduct` - Dimension in inches to deduct from the assigned panel's height and width.

* `Panels` - Number of sashes within this the operable window. For each panel, a panel detail tile will be added below.

* `Glass Bites` - Set the glass bite depth in inches for the:
 
    * `L` - Left
    * `R` - Right
    * `T` - Top
    * `B` - Bottom

---

## Panel Details

* Operation per panel:

    * For Hinged Windows:

        * `Hinge` - Hinge location. Options include:
            * `Top`
            * `Bottom`
            * `Left`
            * `Right`
            * `Fixed`

    * For Hung Windows:

        * `Slide` - Slide direction. Options include:
            * `Up`
            * `Down`
            * `Fixed`

    * For Sliding Windows:

        * `Slide` - Slide direction. Options include:
            * `Left`
            * `Right`
            * `Fixed`

* `Profile` - Set the stile/rail profile per panel if different from the `Default Profile` set above.
