WinBidPro comes with in-depth customization options to help you configure and build out your own catalogs, or add new systems to your team's copy of the vendor catalogs.

:::warning
    Please review the [Local & Global Catalog Edits](../features-and-tips/config-levels) page before getting too deep into custom configurations. 
    
    This page covers important information on how edits and additions work, and where they're stored after you make them.
:::

## Types

You can find a brief description of each type of custom object below. Click each topic's page on the left for more details.

### Framing Systems

By editing or adding custom Framing Systems, you can add new or alternate parts and assemblies, and change things like default glass bites and caulk joints sizes or setting verticals to interrupt the head and sill. 

:::warning
    Changes made here will effect your optimized lists, shop drawings, and reports, so it's important to know what configurations are possible, and that they're set up correctly before using them on an active job.
:::

### Parts

Custom Parts can be added or edited in a similar way to Framing Systems, but are more independent than Framing Systems. 

Custom parts can be added directly to optimized lists, or you can add them to a Framing System's components to have them counted automatically with your elevations.

### Special Categories

Some custom objects have special data sets and restrictions, and are intended to be use with specific tools or options. These include:

* `Finishes` - Frame finish options. Applied in the elevation details menu or [Elevations Overview](../optimization/elevations-overview) optimizer.

* `Entrances` - Combination of door frame and door leaf configurations. Applied in the [Entrances](../drawing-elevations/entrances) tool tab.

    * `Doors Frames` - Door frame configurations. Applied in the [Entrances](../drawing-elevations/entrances) tool tab.

    * `Door Leaves`- Door leaf configurations. Applied in the [Entrances](../drawing-elevations/entrances) tool tab.

* `Operable Window Templates` - Special panel types representing operable windows. Applied using the [Operable Windows](../drawing-elevations/operable) tool tab.

* `Glass Products` - Glass types assignable to panels. Applied using the [Glass](../drawing-elevations/glass) tool tab.
