In WinBidPro, all catalogs and certain settings have two levels of configuration - `Global` and `Local`.

You can add and modify framing systems and parts at either level, so it's important to know which is which and where they exist once they're made. 

## Levels

* `Global` - Systems, parts, and settings available to, and active across all jobs and team members.

* `Local` - Systems, parts, and settings only available to, and active on the current job.


### Syncing to the Catalog

If you make a change within a job and want to add the new copy to the catalog, you can press the `Save to Catalog` button in the `Edit Framing System` menu.

### Example

:::tip

    
    The `Edit Framing System` option of the `Elevation` tool tab makes changes at the local level, and **will not be reflected in the Global catalog** unless you sync it. Changes that don't get synced will only exist in the job they were created.

    <div class="app-img"><img src="/screenshots/diagram.png"/></div>

    Similarly, edits made to a system creates a copy of that system and **only applies it to the current elevation**. You'll have an option to apply it to new elevations as you make them, but other existing elevations will need to have their framing system reassigned.
:::

## Best Practices

Before making changes to a catalog, consider how you plan to use the new systems or parts.

* If this is a system you'll want to use again on other jobs or share with your team, add a new system to your catalog.

* If there's something unique about one elevation or all the elevations on a specific job, edit the Framing System in the layout tab.

* If a modified framing system will be used by more than one elevation in your job, try to configure the system on the first elevation so you can easily apply it to the others as you make them.
