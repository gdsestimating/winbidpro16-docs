Part lists and summaries play a major role in your estimates, but these lists can be lengthy. You can use groups and filters to help organize them.

* Groups break your list up into sections by columns and their values. 

* Filters let you limit your lists to specific entries in each column.

* Quick filters are simplified filters used in part selection. These only show up in a few specific places -- for example, selecting a door frame for your entrance.

You can set multiple groups and filters at the same time for a highly customized view.

## Groups

To set a group, drag the column header into the group area at the top of the list. 

Once a group is active, it'll break your list up into sections based on the values found in its column. These sections can be expanded or collapsed by pressing the `▲` / `▼` on the far left of each section header.

If a list has active groups, you'll see the column name in light blue in the group area. You can change the sorting for each group by clicking the center of the blue box. You can remove this group setting by clicking the `X` that appears when you hover over it.

## Filters <img align="right" src="/screenshots/filter-options.png"/>

To set a filter for a column, click the <img src="/screenshots/filter-icon.png"/> filter icon in the column header. 

As you adjust the filter settings, the list will update to preview your settings. You can confirm these changes by clicking the `Filter` button, or remove them with the `Clear Filter` button. 

Filtering options are broken out into value filters and conditional filters -- see the sections below for more details. If needed, you can set both kinds of filters at the same time.

<br clear="right"/>

### Filter by Value 
The top portion of the filter menu contains your value filters. This section lists each unique value in this column and lets you individually turn them on and off. If you need to filter by partial values, see below for conditional filters.

* ☑ `Select All` - When checked, no values are hidden.

    * If values are checked, the filter will default to this even when unchecked.

* Below `Select All` is a list of values set in this column, each with a ☑ checkbox. If one or more values are checked, only line items with those values will be visible.

    * If all the entries in this column are empty, you'll see `[null]` instead.

:::info
    **Example** - Only show systems with a black finish

    1. Click the filter icon in the `Finish` column header.
    2. Check ☑ `Black` in the listed values.
    3. Click `Filter`
:::

### Filter by Condition
Below the value filters, you'll see the label `Show rows with value that` -- this is the conditional filter section.

Conditional filters are filters based on rules rather than specific values. This is helpful when you need to filter line items by a shared trait or partial value, even when those values don't match each other. 



<img align="right" src="/screenshots/filter-conditions.png"/>

These rules are set using operators and values - see **Setting Conditions** below.

You can set up to two conditions at once, and how those conditions apply using the `And` / `Or` option - see **Pairing Conditions** below.

<br clear="right"/>

#### Setting Conditions
Conditions are set by pairing an operator and a value. 

* Operators are a set of options that tell the filter what to do when it finds your typed condition value.

    * Some options like `Is empty` are a complete condition in themselves and don't need a value. When you select these operators, the value box will be locked. 

* Values can be anything you type - this is what the filter looks for in your column entries.

    * <img src="/screenshots/case-match.png"/> `Match Case` - By default, case matching is off for filters. You'll see this toggle for certain columns like `Elevation Mark` where upper and lower case can be particularly important. 

:::info
    **Example** - I want to set a conditional filter for the `Part Type` column in my parts list. 
    
    If I set the first line of my condition to `Contains` and type `e` in the second line, my parts list will be filtered to include lines where with part types like `Screws` and `End Dam`. The list won't include lines with the part type `Anchors` because it doesn't contain the letter e.
:::

#### Pairing Conditions
The setting between the two conditions is how the conditions relate to each other. These options include:

* `And` - Only line items that **meet both conditions** will remain visible.

* `Or` - Line items that meet one or the other condition (or both) will remain visible. Everything else will be hidden.

If you don't have a completed rule for the second condition, this setting is ignored.

:::info
    **Example** - In the framing system catalog, I want to see lines with "Thermal" in their description but not "Pre-Glazed".     

   

    1. Click the <img src="/screenshots/filter-icon.png"/> filter icon in the `Description` column header.
    2. Leave all value filters unchecked or check ☑ `Select All`

    <img src="/screenshots/filter-example.png"/>
    3. Set the first condition:
        * Select the `Contains` operator on line 1
        * Type `thermal` as the value in line 2
    4. Select `And` on line 3
    5. Set the second condition:
        * Select the `Does Not Contain` operator on line 4
        * Type `pre-glazed` as the value in line 5
    6. Click `Filter` to confirm the settings.
:::

## Quick Filters <img align="right" src="/screenshots/quick-filters.png"/>

Where quick filter menus are active, they enable users to quickly find a specific configuration. See the image to the right for an example from the Door Frames catalog.

Each section of the quick filter is pulled from commonly filtered columns, and presents each unique value in the current catalog.

* Click the values to toggle them on / off to set your filtered list. 
* Click `Clear Filters` to reset all toggles to off.

The quick filter menu will be expanded when you first open the catalog. Once you move away from it, it'll collapse the menu and store it on the left edge of the window. To expand it again, hover over the white box on the left edge labeled `Quick Filter`.
