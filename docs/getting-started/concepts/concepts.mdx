## Big Picture

Estimates in WinBidPro are split up into **`Jobs`**. 

A `job` represents a set of glazed openings that use framing systems (storefront, curtain wall, punched entrances, etc) in a project, the parts that go into those openings, and any settings / adjustments like markups and labor. WinBidPro does this by building **`Elevations`** and applying framing systems to them from **`Catalogs`**.

* `Elevations` - The project's glazed openings recreated in WinBidPro. 
    * These are built from the drawing set, but use actual part profiles and assemblies from the `catalog`.

* `Catalogs` - Collections of parts, assemblies, costs, and installation / ordering logic. 

    * These use the `Elevations` to build out parts lists and cost estimates in real time.

Basically, `catalogs` give a `job` product info, while `elevations` give the `job` project info.
