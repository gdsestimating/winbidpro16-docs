## Installing WinBidPro v16
After downloading v16, open the installation file and go through the installation menus. Once installed, a "W" WinBidPro v16 icon will be added to your desktop and start menu. The program will open automatically when the installer is finished.

WinBidPro v16 is a hybrid Cloud based system, so the program is installed on your computer, but all of the data used for quotes and drawings is stored in the Cloud on Amazon AWS servers. This means you can install the software on any computer running Microsoft Windows 8 or newer, login with your email address and password, and still have full access to your company's data.

Apple Mac users can run WinBidPro through virtual machines or booting into a Windows partition. If you're interested in this, customer feedback suggests Parallels and VMWare are solid options.

### Choose Your Vendor Catalogs
The first time you open v16 you'll be prompted to select the vendor catalog(s) you want quick access to. If you ever need to add or remove catalogs from your list, you can click `Catalogs` > `Manage Vendors` at the top of the WinBidPro window.

Whenever you create a new job you'll select one of these catalogs. To avoid mismatched parts or overlapping parts numbers, each Job in WinBidPro can only have one catalog associated with it.

### Home Tab 
Without a job loaded, you'll see this page in the main workspace area. From here you can create or open a job, or review the most recent changes by clicking `Patch Notes`. You'll also get a list of jobs you've recently worked for quick access.

## Catalogs

### Know Your Catalogs
We always recommend that you familiarize yourself with the vendor catalog to start. 

Most catalogs available in v16 have list pricing already configured. A discount multiplier of 1 is set to all parts by default, so it is up to you to enter your company's multipliers for a certain vendor. You can change multipliers in a couple ways:

    * To change them for a specific job use the `Change Multipliers...` option in the `Reports` > `Final Parts` or `Job` > `Edit Job Parts` windows from the main menu at the top of the app.
    
    * The same option shows up in the `Catalog` > `Vendor Parts` window. This version changes the multipliers at the catalog level, which will change it for your entire team and every job moving forward. 
    
        * For more details on job edits and team edits see [Core Concepts Part 3 - Local and Global Edits](./concepts/config-levels).

Aside from pricing, it's important to get familiar with a framing system's parts before using it on a job. 

Each preconfigured framing system is built for accurate drawings and parts lists. Before creating a job, it is always a good idea review how a framing system is configured and what parts are being used. You can do that by clicking the edit option from the framing system catalog.

For more detailed information on configuring systems, see the [Custom Parts & Systems](../custom-parts) section.

## Creating a New Job

<div class="mini-img"><img src="/screenshots/new-job-window.png"/></div>

1. Click on the `Jobs` > `New Job` from the main menu.
2. Select the Vendor to use fom the list.
3. Enter a name for the job.
4. Select a Finish color for the job.
5. Click the `Create` button.

### First Elevation

<div class="mini-img"><img src="/screenshots/sample-new-elevation.png"/></div>

Once you create a job, you'll see the New Elevation window pop-up. 

Here you can either enter a Standard Elevation (default), Punched Entrance or Punched Entrance w/ Transom. Standard Elevations cover most use cases. For those, you'll want to:

1. Enter a mark - you'll usually want to match this to the tags in your drawing set.
2. Add a description (optional).
3. Select a Framing System for this elevation by clicking the `Browse` button.
4. Select a finish option - this defaults to your finish choice at job creation.
5. Select a labor ruleset - see [Labor](../features-and-tips/labor) for details.
4. Click `Save` to continue to the drawing window.

Once you create the elevation, it'll need some basic details before it show up in the elevation view. Below the viewer, you'll see your tool tabs. Input a height, width, # of panels and quantity. Once those are set, you'll have access to the other tool tabs which you'll use to refine the elevation.

See the [Basic Workflow](./basic-workflow) page for a breakdown of a typical job from here, or refer to specific sections of the docs for details on each of the steps.
