## Closing and Detaching Tabs

You can click the `X` on a tab or sidebar to close it. 

* To reopen elevation views, click on the elevation in the `Job Explorer`. 
* To reopen sidebars, toggle them from `View` in the main menu.
* To reopen report windows, click on them from `Reports` or `Job` in the main menu.

You can also right-click tabs and sidebar headers to see options for detaching or hiding them. Clicking and dragging the header out of place will also detach it. 

* While detached, you can move the floating windows to other screens to open up space on your main window.

:::tip
    The `Job Explorer` sidebar and `Tool Tabs` are core elements of the interface and can't be closed or detached.

    Likewise, certain interface windows are always detached, like catalog windows. You can recognize these by the <img src="/favicon-16x16.png"/> WinBidPro logo in the top left and the `🗕` minimize, `🗖` maximize and `X` close buttons in the top right.
:::




### Docking a Floating Window

A detached window can be reattached, or *docked*, in the original spot or new ones. You can use this feature to make big changes to your workspace, like splitting the main window. 

1. To dock a floating window, click and drag it over the main window to see docking widgets.

2. While dragging over one of these widgets, its arrows will be highlighted in a darker gray color. Holding it here for a moment will show you a transparent gray box to preview where the window will be docked.

3. Release your mouse button while an option is highlighted to confirm your choice.

## Auto-Hiding Sidebars

Sidebars can be set to collapse when you're not using them. Where available, you can click the <img src="/screenshots/interface/pin.png"/> pin button to toggle this.

* If the pin is active (vertical), this sidebar will stay visible at all times. 

* If the pin is inactive (horizontal), the sidebar will automatically be hidden if you're not hovering over it.

## Customizing CAD Views

Elevation views can be customized using the Layer Settings sidebar. Toggle this sidebar on by clicking `View` > `Layer Settings` in the main menu. 

This menu includes options to hide and stylize almost anything in CAD views. You can even save multiple presets of these settings and quickly switch between them. 

You can see an overview of the available layer settings in the [UI Reference Guide](../getting-started/interface/sidebar#layer-settings).
