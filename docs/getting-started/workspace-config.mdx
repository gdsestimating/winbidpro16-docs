## Organization

Clicking and dragging the tab of a window will detach it from the WinBidPro interface. Clicking the `X` on a window's tab will close it.

The Job Explorer and Tool Tabs are always active and cannot be detached or closed.

Certain interface windows -- like framing system configuration -- are always detached. These are recognizable by the <img src="/favicon-16x16.png"/> WinBidPro logo in the top left and the `🗕` minimize, `🗖` maximize and `X` close buttons in the top right.

### Organizing Job Windows

Dragging a window's tab will automatically detach it from the WinBidPro interface. 

To reattach the window, drag it to one of the docking arrows. This will highlight the option in a darker gray color. Release your mouse button while an option is highlighted to confirm your choice as shown below.

### Pinning Sidebar Menus

Where available, you can click the <img src="/screenshots/interface/pin.png"/> pin button to switch the sidebar mode for certain windows, like the `Job Explorer`. 

* If the pin is active (vertical), this window will stay visible at all times. 

* If the pin is inactive (horizontal), the window will automatically be hidden if you're not hovering over it.
