## Welcome Page <img align="right" src="/screenshots/interface/welcome.png" width="40%"/>
The welcome page has a quick access menu for your jobs, some information about the latest updates to WinBidPro, and some tips to get your started with newer features.

This menu can be toggled off with the ☑`Hide welcome tab on startup` checkbox below the list of recent jobs on the welcome page, or by clicking ☑`Show Welcome Page on Startup` in the `View` toolbar menu.

You can also re-open this page after closing it by clicking `Show Welcome Page` in the `View` toolbar menu.

<br clear="right"/>

## Elevation View <img align="right" src="/screenshots/interface/elevation-view.png" width="40%"/>

The elevation view is a CAD interface where you'll see live updates to the elevations in your job. 

For information about how to navigate CAD view like this one see [Navigation - CAD Views](./navigation#cad-views).

Each elevation in your job will open its own tab when you click on it in the `Job Explorer`, and each tab will be labeled with the Mark of the elevation.
