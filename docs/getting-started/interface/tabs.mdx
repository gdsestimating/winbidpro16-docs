This sections covers the main workspace of WinBidPro, where `Elevation` views and most `Reports` can be docked as tabs.

## Organizing Tabs

* Clicking and dragging the tab at the top of the view will detach it from the app. You can reattach a floating window by dragging back over the main workspace.

    * See [Setting Up Your Workspace](../workspace-config) for details on this this and more.

## Tab Windows


### Elevation Views <img align="right" src="/screenshots/interface/elevation-view.png" width="40%"/>

Selecting an elevation from the `Job Explorer` will open a tab for that elevation.

* This CAD view will update as your refine your elevations. 
    
    * See the [Drawing Elevations](../../drawing-elevations/) section for more details.

* See [Navigation - CAD Views](./navigation#cad-views) for more info on how to use CAD views like this one.

<br clear="right"/>

### Reports <img align="right" src="/screenshots/reports/cut-list.png" width="40%"/>

Most reports in the `Reports` or `Job` menus will open the window as a tab by default.

* See the [Finalizing Your Estimate](../../finalize/) section to learn more about reports.

* See [Grouping & Filtering Lists](../../features-and-tips/filters) to learn more about organizing these views.
