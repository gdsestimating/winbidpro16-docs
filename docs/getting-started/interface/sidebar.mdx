### Job Explorer<img align="right" src="/screenshots/interface/job-explorer.png"/>
A summary of elements loaded or built out in the current job.

* All [Elevations](/docs/16/drawing-elevations/) in the current job are listed here.

* Expand `Data Tables` for list of loaded:
    * Framing Systems
    * Glass Products
    * Labor Rulesets

* Here, you can right-click the job name for quick-access list of job options.


<br clear="right"/>

### Reports Explorer<img align="right" src="/screenshots/interface/reports-explorer.png"/>

A quick-access menu to all the reports found in the `Reports` toolbar menu.

* `Search` - Find specific reports in the list.

* Use the pin icon next to each report to build out a custom quick-list.

* Use the gear icon to change options for printed reports and labels.


<br clear="right"/>

### Elevation Totals<img align="right" src="/screenshots/interface/elevation-totals.png"/>

Provides a live update of counts, cuts, joints, areas, perimeter, and labor for the current selected elevation. 

<br clear="right"/>

## Layer Settings<img align="right" src="/screenshots/interface/layer-settings.png"/>

Manage visibility settings and colors for all text, lines, and hatches in the elevation view.

* `Configuration` - Use this section to build out, and switch between different sets of settings.

* `Search` - Find a specific element.

* Each piece of an elevation is broken out into sections like `Frame` or `Glass`

* For most drawn linework you can:

    * Toggle between `Visible`, `Hidden`, or `Excluded from Export`. 

    * Switch the default layer color by clicking the color swatch next to the toggle options.

* For panel elements, like `Glass` and `Operable Windows` you can also change the fill pattern between a handful of presets.

* `Dimensions` - Dimensions share their visibility settings and color but include options to toggle on or off specific types of dimensions.
    
    * This is also where you set your units for dimensions.

    * Some dimensions, like `Arch Radius`, include options to scale the dimension.

* `Displayed Text` - Change the formatting of dimension subtext for things like rough openings, and for other non-dimension text.

* `Selections` - Change how something looks when it's selected or hovered over.

* `Misc` - Allows you to change the background color of the elevation view.

* `Editor Settings` - Opens the editor settings menu. Also can be found under the `Settings` toolbar menu.

* `Reset to Default` - Reset all setting back to WinBidPro defaults.
