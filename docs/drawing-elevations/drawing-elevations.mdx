Elevations are your glazed frames, openings, entrances, borrowed lites, storefront, curtain wall, etc. These are the core of all jobs in WinBidPro. 

Once an Elevation is built out with a configured Framing System applied, reports will start to show the parts and pieces needed to achieve that elevation.

## New Elevations

You'll be asked to make a starting elevation when you make a new job. You can see more about that process on the [Getting Started](../getting-started/) page.

While you're in a job, more elevations can be added by:

* Clicking `Job` in the toolbar and selecting `New Elevation`

* Pressing `Ctrl`+`N`
* Right-clicking in the `Job Explorer` and selecting `Add New Elevation`
    * Existing elevations can also be copied as a starting point for new elevations by right-clicking them in the `Job Explorer` and selecting `Copy Elevation`.

The new elevation window will appear with some options.

<div class="app-img"><img src="/screenshots/new-elevation-window.png"/></div>

* `Elevation Type` - A choice of Standard Elevation, Punched Entrance or Entrance w/ Transom

    * `Standard Elevation` - A glazed opening with options to add entrances, borrowed lites, etc
    * `Punched Entrance` - A punched opening meant for a framed door without transoms or sidelites
    * `Entrance w/ Transom` - A punched opening meant for a framed door and transom but without sidelites
* `Mark` - A unique mark for the elevation -- Also known as a tag or code
* `Description` - An optional description of the elevation
* `Framing System` - The configured framing system to use with this elevation
* `Finish` - The finish applied to your framing system
* `Labor Ruleset` - The rules for estimating labor.


## Drawing an Elevation
<div class="app-img"><img src="/screenshots/tool-tabs/editor-layout-1.png"/></div>

At the bottom of the screen you'll see your tool tabs. Each tab has different tools and settings to help define your elevations. 

To start, use the `Elevation` tab to assign a minimum of one `Panel`, an `Original Height` and an `Original Width` to draw a preview of your elevation. 

Once a preview is drawn, selecting system frames and glass panels becomes available for other tool tabs like `Horizontals` and `Entrances`.

### Tool Tabs

Tool tabs can be found on the bottom of the main WinBidPro window and are the main way to build out elevations. Each tab focuses on a specific component of an Elevation.

You can find a brief description of each tab below, and more details on each tool tab and what they offer by clicking its page on the left.

* `Elevation Tab` - Set height, width, number of panels, and other core details for the current elevation. Until these are set, the other tabs will not be available.

* `Adjust Panels Tab` - Add fixed height and width rules, or a bulkhead, to specific panels.

* `Horizontals Tab` - Manage horizontal framing and divide panels.

* `Entrances Tab` - Manage door frames and door leafs.

* `Splices Tab` - Manage splice locations.

* `Merges Tab` - Merge panels for irregular layouts.

* `Rakes Tab` - Manage raked elevations.

* `Arches Tab` - Manage arched elevations.

* `Alternate Tab` - Assign alternate parts to framing assemblies.

* `Exclude Tab` - Exclude frame segments and associated parts from reports.

* `Glass Tab` - Assign glass products to panels.

* `Stops / Adapters Tab` - Assign glass stops and adapters to panels.

* `Operable Windows Tab` - Assign operable windows to panels.

* `Annotations Tab` - Add annotation text and leaders to elevations and drawings.

* `Joints Tab` - Change visibility and highlighting for different types of joints. Joint conditions are specified in the framing system configuration.

* `Labor Tab` - Assign labor pricing rulesets and settings.

### Tips

:::info
    Any change to an elevation using tool tabs is non-destructive. 
    
    This means you can add, edit, or delete a tool tab option without breaking the elevation or other tab tool options. If two configurations are conflicting, you can delete or edit one of the two configurations until you get something that works.
    
    No need to start from scratch! 
:::

:::warning
    Any edits to catalog entries from the tool tabs will create a **copy** of the original and **need to be synced** to be used on other jobs.

    See [Local & Global Edits](../features-and-tips/config-levels) for more information.
:::
