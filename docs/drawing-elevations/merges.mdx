Combine two or more adjacent panels together.

This tab lists all applied merges in this elevation with a button to delete them. If merges haven't been added, the list will show `No Merges` instead.

<div class="app-img"><img src="/screenshots/tool-tabs/editor-merge-3.png"/></div>

## Merging Panels

Click the `Add` button to create a new merge condition.

Your tab will switch to a new view where you can select the panels you want to join together.

:::tip
    Merges only apply to vertical framing. For partial horizontal framing, adjust your settings in the [Horizontals](./horizontals) tool tab.
:::

<div class="app-img"><img src="/screenshots/tool-tabs/editor-merges.gif"/></div>

### Process

1. Click `Add` to start a new merge condition.
2. Select two or more panels to merge.
3. Confirm your choices.

### Confirm / Return

Click `Save` to confirm your selection and apply them to the elevation.

Click `Cancel` to return to the list of all merges.
