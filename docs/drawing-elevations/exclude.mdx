Disable specific vertical/horizontal elements in the elevation frame.

<div class="app-img"><img src="/screenshots/tool-tabs/editor-exclude-3.png"/></div>

The Excludes Tool Tab will show a list of excluded frame segments on your current elevation. You can use this list to quickly review, or delete existing exclusions.

Applied exclusions will appear in the elevation as dashed lines.

If exclusions haven't been applied to this elevation, the list will show `No Excluded Elements`.

## Exclude Elements

Click the `Edit` button to apply a new exclusion.

Your tab will switch to a new view where you can select the frame segments you want exclude.

<div class="app-img"><img src="/screenshots/tool-tabs/editor-exclude-2.png"/></div>

### Confirm / Return

Click `Save` to confirm your settings and return to the list view.

Click `Back` to cancel and return to the list of exclusions applied to the elevation.
