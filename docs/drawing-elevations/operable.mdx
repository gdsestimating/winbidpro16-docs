Apply operable windows to selected panels.

The Operable Windows tool lists window templates loaded into the current job. Once applied, they'll appear as window sashes with swing lines.

The list shows `Start by adding a template to the job` if no templates are loaded. For window counts to be reported, **templates need to be applied to panels**.

<div class="app-img"><img src="/screenshots/tool-tabs/editor-window-2.png"/></div>

## Setting the Template List

The Operable Windows tool tab uses window templates to represent windows on an elevation. 

WinBidPro has templates that cover most operable window types. You can add new a template or copy existing ones and modify them as needed. See [Configuring Operable Window Templates](../custom-parts/config-window) for more details.



* `Add Template to Job` - Load a window template to a job.

* `Purge Unused Templates` - Unload any templates that aren't in use.

## Adding Windows

To add windows, make sure a template is loaded. Select the template, click `Add`, and click the panels to apply it.

:::tip
    Operable Windows are applied to the entire panel. Use the `Horizontals`, `Entrances` and `Merges` tool tabs to get the panel sizes right before applying your windows.
:::

<div class="app-img"><img src="/screenshots/tool-tabs/editor-windows.gif"/></div>



### Options

* `Add` - Click `Add` with a template selected, then click panels to apply it. 

* `Delete` - Click `Delete` then click the windows to remove.
