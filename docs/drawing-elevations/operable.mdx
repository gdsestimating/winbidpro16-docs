The Operable Windows Tool Tab will show a list of window templates loaded on the current job. When these templates are applied to an elevation, they'll appear as window sashes with swing lines.

A preview of your applied operable windows will appear in your elevation.

If operable window templates haven't been added to this elevation, the list will show `Start by adding a template to the job`. Windows cannot be added without a template loaded.

## Setting the Template List

The Operable Windows Tool Tab uses window templates to represent windows on an elevation. 

WinBidPro has templates that cover most operable window types. You can add new a template, or copy existing ones and modify them to match your specified window. 

{/* See [Configuring Operable Window Templates](../custom-parts/config-window) for more details. */}

* `Add Template to Job` - Load a window template to a job. Once a template is added you'll see it on the template list in the Tool Tab.

* `Purge Unused Templates` - Unload any templates that aren't in use in the current job.

## Adding Windows

To add windows, make sure a template is loaded and available from the list. Select the template you want to use, click `Add`, then click the panels you want to convert to operable windows.

:::tip
    Operable Windows are applied to the entire selected panel. Make sure to use the `Horizontals`, `Entrances` and `Merges` Tool Tabs to create the right opening size before applying your windows.
:::

<div class="app-img"><img src="/screenshots/tool-tabs/editor-windows.gif"/></div>



### Options

* `Add` - Click `Add` with a template selected, then select panels to convert to windows. 

* `Delete` - Click `Delete` on the left and then select windows in the elevation to remove.

Once a window template is applied to a panel, the preview will update to show where and what kind of windows are applied.
