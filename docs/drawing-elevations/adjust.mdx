Add fixed height dimensions, fixed width dimensions or bulkheads to individual panels. 

<div class="app-img"><img src="/screenshots/tool-tabs/editor-adjust-3.png"/></div>

The Adjust Panels Tool Tab will show a list of adjustments made in your current elevation. You can use this list to quickly review, edit, or delete existing adjustments.

If adjustments haven't been made to any panels in this elevation, the list will show `No Panel Adjustments`.

## Adding Adjustments

Click the `Add` button to create a new panel adjustment. 

Your tab will switch to a new view where you can select panels and create new adjustments.

<div class="app-img"><img src="/screenshots/tool-tabs/editor-adjust-2.png"/></div>

### Types and Options

* `Width` - Limit selected panels to a specified `Width`.

* `Height` - Limit selected panels to a specified `Height`, measured from the bottom of the panel.
* `Bulkhead` - Raise the sill of selected panels by a specified `Bulkhead Height`.

### Confirm / Return

Click `Add` to confirm your settings and apply them to the elevation.

Click `Back` to return to the list of all panel adjustments.
