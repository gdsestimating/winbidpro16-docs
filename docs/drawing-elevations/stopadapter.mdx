Apply stop or operable window adapter options to selected daylight openings.

The Stops/Adapters tool tab lists glass stops and operable window adapter options loaded into the current job.

The list shows `Start by adding an option to your framing system` if no options are configured. To add these to your elevation, you'll need to edit your framing system. See [Configuring Opening Options](../custom-parts/framing-systems/opening) for more details.

<div class="app-img"><img src="/screenshots/tool-tabs/editor-stopadapter-1.png"/></div>

<br/>

:::info
    Stops and adapters can be assigned in a few different ways. If these are assigned in multiple ways at once, the priority is:

    1. Stop/Adapter tool tab assignments
    2. Door Frame transom settings
    3. Auto Applied per frame configuration
:::

## Adding Options

* `Edit/Add Options` - Add or modify stops and adapters available with this framing system. 
    
    * See [Configuring Opening Options](../custom-parts/framing-systems/opening) for more details.

## Assigning Stops / Adapters

### Process

To assign stops/adapters make sure a stop/adapter option is loaded. Select the option, click `Add`, and click the panels to apply it.

:::info
    Operable Window Adapters can only be applied to panels with an operable window assigned.
:::

<div class="app-img"><img src="/screenshots/tool-tabs/editor-stopadapter.gif"/></div>

### Options

* `Add` - Assign the currently selected stop/adapter to the panels you click.

* `Delete` - Remove stop/adapter from the panels you click.

Use these settings to speed up assignment:

* `By Lite` - Default option. `Add` or `Delete` stops/adapters to individual panels.

* `By Row` - `Add` or `Delete` stops/adapters to a full row of panels.
* `By Elevation` - `Add` or `Delete` stops/adapters to all panels.
