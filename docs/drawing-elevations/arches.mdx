The Arches Tool Tab will show a list of arches applied in your current elevation. You can use this list to quickly review, edit, or delete an existing arch.

Currently, only one arch can be applied to an elevation.*

<div class="app-img"><img src="/screenshots/tool-tabs/editor-arch-1.png"/></div>

## Arch Drop

You can find an option to set a custom Arch Drop in `Settings` > `Team Settings`. This lets you customize the drop length added to your cuts at arch conditions.

:::warning
    Arch Drop values **will effect your entire team**. Once you set this value, it will apply to all new jobs **after the `Arch Drop` is set**. 
:::

## Adding an Arch

Click the `Draw New Arch` button to apply an arch, see Modes and Types below for more details.

<div class="app-img"><img src="/screenshots/tool-tabs/editor-arch.gif"/></div>

### Mode

* `Arc Height` - Move your mouse to change the `Start Y` value in inches, then left-click to confirm. 

    * The `Y` value here is the height from the base of the arch to the bottom of the elevation.

* `Radius` - Move your mouse to change the `Radius` in inches, then left-click to set the arch. 

    * The `Radius` here is the distance from the top of the elevation to the center of the arc.


### Options
* ☑ `Continuous Head` - If your radius is small enough, the option to toggle a continuous head assembly will appear. For larger radiuses (shallower arch), a continuous head is automatically applied.

* When your arch is set, you can hit the `Esc` key before clicking `Add` to unset and adjust it. Left-click to set the arch again or type in your `Start Y` / `Radius` value manually.


### Types

* `Center` - Locks the center of the arch radius to the middle of the elevation's width.

* `Left Corner` / `Right Corner` - Locks the center of the arch radius to the bottom left / right corner of the elevation.

    * Currently, this option is only available for elevations with Widths less than or equal to their Height.*

### Confirm / Return

Click `Add` to confirm your settings and return to the list of arches applied to the elevation.

Click `Cancel` to cancel and return to the list of arches applied to the elevation.
