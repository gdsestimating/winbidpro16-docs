You can create cut and glass labels based on your [Cut List](../finalize/finalize#cut-list) and [Glass](../finalize/finalize#glass) summaries. This page goes over the options and exports of this feature. 

You can reach the `Cut List & Glass Labels` option under the `Reports` toolbar menu.

<div class="app-img"><img src="/screenshots/reports/print-labels-1.png"/></div>

## Cut List Labels

### Options

* 🔘 `Small` - Click to change the output to small labels (1/2" x 1-3/4"), like Avery 5267 or 5167 labels.

    * Includes 5 configurable slots for cut list column values for each cut and a marker for cuts that share a stock.

* 🔘 `Large` - Click to change the output to large labels (1" x 2-5/8"), like Avery 8160 labels.

    * Includes 11 configurable slots for cut list column values for each cut and a marker for cuts that share a stock.

* ☑ `Add Label marker icon for cuts in the same stock` - Toggle same stock markers.

* ☑ `Print label legend (first label shows field names)` - Toggle having a value legend for reference as the first label in the set.


:::warning
    Fabricators should verify all miter angles against shop drawings before cutting. The displayed angles should be double-checked for accuracy.
:::

### Output

* `Cut Labels` - Click to review the cut label output and print once your options are set.

    * ☑ `Display Marker` - Toggle stock marker display.

    * `Format of Imperial Measurements` - A drop menu to select measurement style with options for:

        * `Fractional` - For example -- 1 1/2"

        * `Decimal` - For example -- 1.5"

* `Reset Cut List Defaults` - Click to reset all cut label settings to the default.

## Glass Labels

### Options

* 🔘 `Small` - Select this option to change the output to small labels (1/2" x 1-3/4"), like Avery 5267 or 5167 labels.

    * Includes 6 configurable slots for glass summary column values for each glass pane.

* 🔘 `Large` - Select this option to change the output to large labels (1" x 2-5/8"), like Avery 8160 labels.

    * Includes 12 configurable slots for glass summary column values for each glass pane.

* `Print label legend (first label shows field names)` - Toggle having a value legend for reference as the first label in the set.

### Output

* `Glass Labels` - Click to review the glass label output and print once your options are set.

    * `Format of Imperial Measurements` - A drop menu to select measurement style with options for:

        * `Fractional` - For example -- 1 1/2"

        * `Decimal` - For example -- 1.5"

* `Reset Glass Defaults` - Click to reset all glass label settings to the default.
