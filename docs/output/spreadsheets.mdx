Many reports will have the option to <img src="/screenshots/reports/export-icon.png"/> `Export to CSV`. 

CSV is a file format that can be imported into spreadsheet programs like Microsoft Excel and Google Sheets.

* For Excel, you can find this option in the `Data` tab, using the `From Text/CSV` button.

* For Google Sheets, you can use the `Import` option in the `File` menu.

* This is a commonly used format, so be sure to check the documentation for any other apps if needed.

## Exporting

Most reports have an <img src="/screenshots/reports/export-icon.png"/> `Export to CSV` button near the top of the window.

<img src="/screenshots/reports/download-csv.png"/>

### Bulk Export

You can also export these in bulk from `Reports` > `All Reports & Settings` in the main menu. 

From this window, you can toggle the CSV option for each report, then click `Run Reports` to download them all at once.
