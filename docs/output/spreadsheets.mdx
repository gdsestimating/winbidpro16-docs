For some [Printed Reports](../output/reports) and [Optimized Lists](../optimization/optimization), you'll see an option to export as a CSV file. 

CSV stands for Comma-separated Values, and is a file format that can be easily imported into spreadsheet programs like Microsoft Excel and Google Sheets.

* For Excel, you can find this option in the `Data` tab, using the `From Text/CSV` button.

* For Google Sheets, you can use the `Import` option in the `File` toolbar menu.

* This is a commonly used format for table data, so similar programs will most likely have a similar import option.

## Exporting Lists

When you're in a optimized list view, you can export your current list as a CSV file using the export to CSV button

## Bulk Export

You can bulk download CSV file links for your reports by clicking `All Reports & Settings` in the `Reports` toolbar menu. From this window, you'll be able to toggle the CSV button for each report and clicking `Run Reports`
