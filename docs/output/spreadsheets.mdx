Some reports will have the option to <img src="/screenshots/reports/export-icon.png"/> `Export to CSV`. 

CSV is a file format that can be imported into spreadsheet programs like Microsoft Excel and Google Sheets.

* For Excel, you can find this option in the `Data` tab, using the `From Text/CSV` button.

* For Google Sheets, you can use the `Import` option in the `File` toolbar menu.

* This is a commonly used format, so be sure to check the documentation for other apps.

## Exporting

Most reports have an <img src="/screenshots/reports/export-icon.png"/> `Export to CSV` button near the top of the window.

<img src="/screenshots/reports/download-csv.png"/>

### Bulk Export

You can also export these in bulk in `All Reports & Settings` under `Reports` in the toolbar. 

From this window, you'll be able to toggle the CSV for the reports you want, and then click `Run Reports` to download them.
