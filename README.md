# WinBidPro Documentation

Docusaurus 3 site for V16 and V15 documentation at [docs.winbidpro.com](https://docs.winbidpro.com).

## Setup

Requires Node.js 20+ and npm. Install locked dependencies with installation scripts disabled:

```sh
npm ci --ignore-scripts
```

## Development

```sh
npm start
```

Starts a development server with live updates. Local search requires a production build.

## Build and preview

```sh
npm run build
npm run serve
```

The build checks links and generates static files and search indexes in `build/`. Preview search and image zoom here before publishing. Rebuild after content changes to refresh the preview and indexes.

Use `npm run clear` to remove generated output and caches if they become stale.

## Editing

| Location | Content |
| --- | --- |
| `docs/` | Current V16 documentation |
| `versioned_docs/version-15/` | V15 documentation |
| `glossary/` | Published glossary (`.md` / `.mdx` files) |
| `src/pages/`, `src/components/homepage/` | Homepage and feature descriptions |
| `src/css/custom.css` | Shared styles |
| `static/` | Public images, GIFs, and other assets |
| `docusaurus.config.js` | Navigation, versions, and plugin settings |

Documentation sidebars are autogenerated. `_old/` is archived source and is not published. Everything in `static/` is copied into the public build.

## Search

EasyOps search runs locally in the browser. V15 has its own index; V16 and the glossary share an index. Only documentation is indexed; AI and explicit breadcrumb paths are disabled.

EasyOps and its `debug` dependency are pinned in `package.json`. Review updates before changing the pins, and commit `package-lock.json` with dependency changes.

## Publishing

Run the production build and publish the contents of `build/` to the static host. Verify search, version switching, and image zoom on the live site. The configured production URL is `https://docs.winbidpro.com/`.
